# vehicle-tutorial

This repository contains the example code and exercises for [the Vehicle tutorial].

[the Vehicle tutorial]: https://vehicle-lang.github.io/tutorial/

## Guide

Resources from the tutorial can be accessed in two ways: through the corresponding chapter folder, or through the `resources-by-dataset` folder. This is done to make resources easy to find for both those working their way through the tutorial, and those who are simply looking for examples from a specific dataset. In each chapter folder, the code referenced in the main body of the chapter can be found in `chapter-code`. The code needed for the exercises at the end of each chapter is kept in `exercises`, and the model solutions to these exercises are in the `solutions` folder.

The `resources-by-dataset` folder also contains all resources for a given dataset under the same folder. **For anyone who might edit the structure of this repository, please be aware that this folder actually contains the majority of all files referenced in this repository**. Most of the files in the chapter folders are actually just symbolic links to these files.
