# Vancomycert

Chapter 6 is a reproducibility-oriented case study showing how Vehicle exports
a neural-network pharmacokinetic specification to an interactive theorem
prover and how that result is incorporated into the Vancomycert proof.

The supporting material is
[Vancomycert artifact](https://doi.org/10.5281/zenodo.20717396). It contains the
Vehicle specification, ONNX model, IDX data and proof sources used by the
chapter and is tied to Vehicle 0.25.1.

The artifact is approximately 5 GB, so it is not duplicated in this tutorial
repository. Chapter 6 is an integrated case study rather than a separate set of
tutorial exercises, therefore this chapter has no `chapter-code`,
`exercises`, or `solutions` .
